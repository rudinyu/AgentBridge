## 實際離線畫面操作

在桌面未鎖定，且既有輔助使用／螢幕錄製權限可用時，透過實際介面及假供應商執行檔完成：

1. 沒有 Git 專案時開啟聊天首頁，新增 Codex 聊天。
2. 傳送花園追蹤工具需求，代號為「Maple Lantern」。
3. 在同一聊天切換 Claude 帳戶並追問；假供應商的私人提示紀錄確認收到已同意的 Codex 內容。
4. 檢視目的位置、回合、確切內容及 SHA-256 摘要，明確建立本機 Git 專案。
5. 確認專案顯示兩個共享記憶回合，再送出專案追問；提示內容包含原代號與討論。
6. 重新開啟原討論，確認兩個回合仍保留。

測試儲存庫的初始提交沒有檔案、狀態乾淨且沒有遠端。此畫面操作沒有使用既有使用者儲存庫，沒有呼叫真實模型、使用 API credits 或供應商憑證。

這次操作早於最後的歷史順序與立即取消狀態修正；前者已通過針對性／完整測試，後者通過最終 Release 編譯。追加的最終版取消按鈕畫面測試，因前置檢查時桌面已鎖定而**未啟動**。最終封裝版的立即取消按鈕顯示與操作仍待畫面驗收；核心取消已有自動測試。

本工作內的唯讀自查涵蓋已追蹤與未追蹤的核心、App、CLI、測試、封裝、測試環境及文件變更與相關呼叫處；已修正歷史順序、過期預覽容量、立即執行狀態、版本顯示與翻譯問題。沒有發現其餘阻擋問題；未另跑原生獨立審查或巢狀 Codex 程序。

# 自主工作流程與擴充執行

[English](AUTONOMY_AND_EXTENSIONS.md)

## 目的

AgentBridge 依明確目標協調本機 Codex 與 Claude Code 程序。使用者先檢視產生的任務計畫，再允許執行。流程可平行派送獨立任務，並協調實作、審查、驗證與有限次修正。原始 Repository 只作為固定提交版本的來源；成果留在受管理的隔離工作區，直到使用者透過既有變更流程檢視並套用。

本文件描述 AgentBridge 0.8.0 的實作契約。建置、測試與發佈狀態分開回報；先前已公證的 0.7.0 壓縮檔不包含這些新增功能。

## 流程核准

模型產生的計畫是資料，不是授權。協調器驗證識別碼、相依關係、支援角色與大小限制，拒絕循環及不存在的相依任務，再提供使用者檢視。核准以摘要雜湊綁定目標、所選供應商與帳戶、來源版本、執行上限、驗證政策，以及已核准的擴充設定。

角色分開處理調查、修改與審查，每個任務使用受管理的工作階段。獨立任務可在最多三個並行工作的限制內同時執行。修正只限核准範圍與審查輪數，最多三輪。模型產生的要求不能授予額外工具、啟用擴充、切換帳戶、開啟付費 API 或核准發佈。

規劃與自主執行使用官方 CLI 的訂閱登入，不能自動轉用 API。每次受管理的供應商呼叫仍受既有本機用量控制限制。本機執行上限會預留規劃、審查與修正的呼叫嘗試；即使在啟動前遭拒絕，也可能消耗本機次數，與供應商帳戶額度分開。

## 執行與證據

只有前置任務成功完成後，才可執行下游工作。前置任務失敗、審查格式無效、超過上限、核准綁定變更或取消，都會阻止後續相依工作。協調器保留有限大小的狀態與事件記錄，讓 App 與 CLI 顯示同一個流程。中斷的流程不會在 App 啟動時自動重跑。

寫入任務使用隔離變更工作階段及既有的工作計畫核准邊界。跨供應商審查必須取得實際產生的完整 diff 與摘要雜湊，不可假設另一份 checkout 能看到尚未提交的檔案。審查結論代表模型的判斷；驗證證據來自已核准驗證程式的實際退出結果。流程完成不會自動接受變更、commit、push 或 merge。

取消會停止派送新節點並傳遞到正在執行的子程序。時間、呼叫次數與修正輪數共同限制自主活動。輸出與進度記錄沿用既有遮蔽和大小限制。互動終端逐字稿不會匯入。

## 執行上限

| 控制 | 目前上限 |
| --- | --- |
| 並行調查代理 | 1–3 個 |
| 審查／修正輪數 | 1–3 輪 |
| 流程時間 | 30–3,600 秒 |
| 受管理的供應商呼叫嘗試 | 1–24 次，包含規劃 |
| 流程每次供應商執行、每台 MCP 伺服器的呼叫 | 預設 16 次；伺服器設定較低時取較低值 |
| 每次執行的代理票證 | 20 分鐘 |
| 滑鼠座標使用的截圖 | 8 秒內，且須符合目前顯示器配置 |
| MCP 協定回應等待 | 每次請求最多 120 秒，設定較低時取較低值 |

呼叫預算必須容納一次規劃、每個調查角色，以及每個核准審查／修正輪次的兩次呼叫。這些是本機執行限制，不是供應商訂閱額度，也不是第三方 MCP 的計費上限。

## 共用記憶

符合條件的工作階段沿用依 Repository 與 commit 區分的共用記憶；供應商 session ID 不等同共用記憶。把前置任務輸出或寫入者 diff 傳給另一個帳戶前，必須確認相關帳戶允許共享。關閉記憶共享後，不能改以流程相依資料的名義傳送相同內容。工具、Skill 與其他 agent 的結果都只是任務脈絡，不能擴大已核准計畫的授權。

核准計畫包含既有專案記憶的有界、遮蔽快照，符合資格的角色會取得這份凍結脈絡。協調器內關閉逐次自動載入與保存，避免停用相依資料共享後，仍透過新追加的共用回合繞過選擇。保存最終流程摘要須另外選擇，並指定允許共享的目標帳戶；只追加回合，不覆寫原有備註。

## Skills 實際載入

既有描述資料登錄仍是中繼資料目錄。實際啟用的 Skill 另行匯入真正 SKILL.md 檔案的有界快照，並記錄內容摘要。匯入本身不執行檔案；使用者明確核准啟用後，才把附帶來源資訊的指令內容提供給受管理的供應商提示。

首版執行器支援可攜式指令內容，不安裝套件、不執行 frontmatter hooks、不展開 shell 表達式，也不自動執行附帶腳本。Skill 指令不能擴大工具權限或覆蓋流程核准。重新匯入不同內容後，原有執行核准即失效。

## MCP 實際連線

首版支援已安裝的本機 stdio MCP 伺服器。執行設定包含絕對執行檔路徑、獨立參數陣列及精確工具允許清單。值透過程序參數或編碼後的供應商設定傳遞，不作為 shell 指令求值。匯入不會執行；命令須直接指定已安裝的執行檔，不接受 env 啟動包裝。由使用者啟動連線檢查、檢視完整設定及查得的工具，並另外同意在指定專案、供應商與帳戶啟用。

MCP 設定只提供給個別官方 CLI 呼叫。AgentBridge 不代為安裝伺服器、不改全域 Codex／Claude 設定、不自行尋找憑證，也不因描述檔或模型提出要求就啟用。受管理的 Codex 呼叫忽略使用者設定檔，並將本次工作區標為不信任以略過專案設定；Claude 使用明確的嚴格 MCP 設定。此隔離保證不涵蓋任意機器管理層的 Codex 政策。連線診斷與設定變更不得把憑證寫入日誌。

執行檔摘要及支援的直譯器入口腳本固定只證明已檢視的啟動檔案，並不涵蓋所有匯入模組、子程序或動態相依，也不保證任意伺服器程式碼安全。

本機 MCP 執行檔是以目前 macOS 帳戶權限執行的受信任程式碼。工具允許清單限制供應商能呼叫哪些伺服器工具，並不替伺服器程序建立作業系統層級的檔案或網路隔離。啟用畫面必須清楚說明此差異。遠端 HTTP／OAuth 伺服器及附帶可執行腳本的 Skill 套件需要另外實作，不能由本機 stdio 支援推論為已完成。

停用或取代執行設定會使啟用核准失效。自主流程的核准包含有效擴充的摘要，因此不能在使用者不知情時取得新啟用伺服器。續用供應商對話時，也不能重新帶入已撤銷的擴充設定。

有期限的票證、收據與代理家目錄放在 Application Support 下每次執行專用的私有目錄，位於供應商工作區與暫存目錄以外，讀取收據後移除。這會將協定證據與一般模型可寫檔案分開，但不限制具備同一使用者權限的受信任執行檔。

可匯入[本機 stdio 範例](examples/extension-runtime-stdio-hello.json)，明確啟動連線檢查，不須呼叫模型。

## Mac Control

Mac Control 預設整合會透過 AgentBridge MCP 代理連接已安裝的 MacControl helper，不沿用本對話的工具權限，也不修改全域 MCP 設定。helper、目標 App 與「觀察／控制」模式一併綁定到核准設定。供應商使用私有且有期限的票證連到代理，不直接啟動 helper。

「觀察」提供已核准的狀態、輔助使用樹與截圖工具；「控制」須額外明確同意鍵盤與滑鼠輸入。代理必須強制使用指定目標 App，拒絕模型改成其他目標，並在觀察模式拒絕輸入。AgentBridge 自身及敏感系統、憑證與終端 App 不能作為控制目標。agent 不會取得要求 macOS 權限或開始錄影的工具；輔助使用與螢幕錄製權限由使用者在 macOS 手動授予。請先自行開啟允許的目標 App，再要求桌面操作。

MacControl 截圖包含整個主要螢幕，也可能包含其他可見視窗。指定目標 App 限制的是輸入，並不裁切圖片。畫面存取同意必須說明這些像素可能傳給所選模型供應商；文字日誌遮蔽無法保護截圖內容。截圖內容與輸入文字不得加入流程稽核訊息。

代理在允許呼叫前檢查目前啟用核准、期限、取消與桌面狀態。「停止控制」撤銷執行授權並取消受影響的受管理工作，無法撤回已送出的輸入。螢幕鎖定或缺少權限時停止桌面操作。憑證輸入、系統驗證、安全設定與重大交易仍由使用者處理；一般桌面授權不包含這些行為。代理會強制檢查 App、模式、就緒狀態與可辨識的安全輸入欄位，但無法可靠判斷一般按鈕的意思或辨識所有重大瀏覽器操作；這是操作範圍政策，不是交易語意偵測器。

桌面與輸入焦點是共用資源，使用相同執行設定儲存區的 AgentBridge 代理之間會序列化桌面存取。不同資料根目錄、其他自動化程式與人工輸入不共用這項鎖定。自主流程只有實作角色能使用 Control，且須另行檢視桌面範圍；調查與審查角色只允許 Observe。執行前及桌面控制後會核對來源指紋，偵測意外的 Repository 變更。指紋涵蓋 Git 追蹤狀態及未被忽略的未追蹤檔案；被忽略的檔案（包含已忽略的機密與產生資料）不在範圍內。偵測不能撤回桌面操作，也不等同檔案系統隔離。

Repository 唯讀設定描述的是供應商的 Repository 工具。明確啟用的外部工具仍可能操作其他系統，包含桌面；其核准範圍與同意是額外邊界，必須在流程計畫中保持可見。

## 驗證

可重現測試使用假的供應商執行與本機 MCP 協定測試伺服器，不依賴憑證或付費服務。涵蓋目標包括相依順序、並行與取消、無效計畫、核准遭竄改、有限次修正、驗證失敗、共享退出、中斷流程、安全檔案匯入、失效的擴充核准、工具過濾、不帶憑證的設定，以及真正 MCP 初始化與工具交換。

官方 CLI 設定會對照本機說明與官方文件。離線測試通過不代表正式供應商登入或模型行為已驗證。畫面測試、真實訂閱執行、簽章與公證是不同驗證層，必須如實分別回報。
